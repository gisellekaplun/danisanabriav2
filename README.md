# Dani Sanabria — Mentoría Laboral (Versión 2)

Landing page para Dani Sanabria, mentora laboral especializada en la conexión entre el talento Gen Z y las empresas.

## Estructura

- `index.html` — Página principal (hero dividido B2C/B2B, propuestas, sobre mí, formulario de contacto).
- `pages/para-vos.html` — Página para el segmento talento (placeholder).
- `pages/para-tu-empresa.html` — Página para el segmento empresas (placeholder).
- `vercel.json` — Configuración de despliegue en Vercel.

## Segmentos

- **Soy talento (B2C)** — Mentoría laboral para estudiantes y recién graduadas.
- **Soy empresa (B2B)** — Consultoría organizacional para retención de talento Gen Z.

## Despliegue

Subido a [Vercel](https://vercel.com).
